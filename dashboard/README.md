# Dashboard

공유오피스 무료체험 고객의 방문·결제 전환과 지점별 성과를 탐색하기 위해 Tableau로 제작한 대시보드입니다.

## 주요 구성

- 방문자 수, 결제자 수, 결제 전환율, 재방문율 KPI
- 기간별 방문자 추이
- 방문자와 결제자 비교
- 지점별 방문자 분포
- 체험 이용 지속기간
- 지점별 리뷰 현황
- 기간·지점·유형 필터

## Tableau Public

[대시보드 바로가기](https://public.tableau.com/app/profile/.79502505/viz/_17854259361800/2)
